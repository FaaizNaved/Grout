Crooked bathroom tiles? Misaligned stairs? Broken heart? Flunked your exams? Leaning Tower of Pisa about to collapse?
**No tension! ISME GROUT BHAR DENGE!**

## 🎮 Game Overview & Features

- **Satisfying ASMR Grouting Mechanics**: Drag your masonry trowel or sponge across the screen to extrude rich, glossy, creamy grout paste into jagged tile gaps.
- **Dynamic Web Audio ASMR Synthesizer**: Procedural wet squelches, metallic trowel scraping, squeaky sponge polish, pentatonic combo chimes, and celebratory brass fanfare (built 100% on the Web Audio API with zero external audio assets needed).
- **Meme Narrative & Voice Clips**: Interactive dialogue between the furious **Thekedar** (Contractor) and the unbothered **Mistri** (Mason) with built-in voice lines:
  - *"Tension mat lo saab, isme grout bhar denge!"*
  - *"Thekedar Shocked, Mistri Rocked!"*
  - *"Dil toot gaya? Koi tension nahi, dil me grout bhar denge!"*
- **7 Escalating Meme Levels**:
  1. **The Crooked Bathroom** (Porcelain tiles with a 2-inch ventilation gap)
  2. **The Viral Staircase** (The exact meme that broke TikTok/Instagram Reels)
  3. **The Broken Heart** (Relationship shattered into two? Grout heals all!)
  4. **The Flunked Exam Marksheet** (00/100 in Physics? Grout converts 'F' to 'A+'!)
  5. **The Shattered Smartphone** (Display cracked into spiderwebs? 50rs paste fix!)
  6. **The Leaning Tower of Pisa** (800-year-old monument tilting? 10 bags of grout at the base!)
  7. **Infinite Mistri ASMR** (Relaxing procedural subway tile sandbox with custom colors)
- **Official "Doctor of Groutology" Diploma Generator**: Generate a personalized certificate of completion stamped by the *All India Council of Jugaad*, downloadable as high-res PNG or shareable on WhatsApp.
- **Viral Sharing Loops**: One-click WhatsApp, Twitter/X, and Reddit shares with custom emojis and high-conversion viral hooks.
- **Haptic Feedback**: Responsive tactile vibration pulses on iOS/Android devices.

## 🚀 How to Run Locally

You can test and run the project locally using Python, Node.js, or any static HTTP server:

### Option A: Using Vite (Node.js)
```bash

```

```bash

```
Open `http://localhost:3000` in your browser.

## ☁️ How to Deploy to Vercel (Step-by-Step)

### Method 1: Push to GitHub & Connect to Vercel (Recommended)

1. **Create a new GitHub repository:**
   - Go to [github.com/new](https://github.com/new)
   - Name it `grout`
   - Set it to **Public**
   - Click **Create repository**

2. **Push your code to GitHub:**
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/grout.git
   git branch -M main
   git push -u origin main
   ```

3. **Deploy with 1-Click on Vercel:**
   - Go to [vercel.com/new](https://vercel.com/new)
   - Log in with your GitHub account.
   - Select the `grout` repository and click **Import**.
   - Framework Preset: **Other** (Root directory: `./`)
   - Click **Deploy**!
   - Your game will be live in 10 seconds at `https://grout.vercel.app` (or your custom domain)!

### Method 2: Deploying via Vercel CLI

```bash
npx vercel
```
Follow the interactive prompts (Accept default settings), and your game will be deployed instantly!
